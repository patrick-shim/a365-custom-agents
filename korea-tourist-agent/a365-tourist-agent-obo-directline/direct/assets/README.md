# Korea Tourist Expert Direct Line icons

- `korea-expert.ico` is the multi-size Windows executable icon referenced by
  `KoreaExpert.Direct.csproj`; it uses the same white field and taegeuk as `color.png`.
- `color.png` and `outline.png` mirror the source-owned Korean-flag package identity used by the
  Microsoft 365 clients.

The 192 x 192 color icon uses a solid white background and the official Taegukgi taegeuk, with Korea
red (`#CD2E3A`) above Korea blue (`#0047A0`) across a horizontal dividing curve. The 32 x 32 outline
icon uses a white disc on transparency.

The PNG dimensions follow the Microsoft 365
[agent icon requirements](https://learn.microsoft.com/microsoft-365/copilot/extensibility/agents-are-apps#app-icons).
