# Korea Tourist Expert package icons

- `color.png`: 192 x 192, solid white background, official Taegukgi taegeuk inside the 120 x 120
  safe region, using Korea red (`#CD2E3A`) above Korea blue (`#0047A0`).
- `outline.png`: 32 x 32, white disc on a transparent background for Teams package validation.

The taegeuk dividing curve is horizontal with red above blue. Never rotate or tilt it; a tilted
taegeuk is an incorrect rendering of the national flag.

These files are source-owned inputs. During the approved `a365 publish` workflow, use the CLI's
manifest-customization pause to replace only the freshly extracted default icons with these files.
Never read or reuse icons from a historical Seoul Tourist manifest or package.

Dimensions follow the Microsoft 365
[agent icon requirements](https://learn.microsoft.com/microsoft-365/copilot/extensibility/agents-are-apps#app-icons).
