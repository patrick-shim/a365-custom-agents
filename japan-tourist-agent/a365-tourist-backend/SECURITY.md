# Security policy

Do not report credentials, tokens, personal data, prompts, responses, tool content, or matched
sensitive values in a public issue.

Until a public security contact is configured, report suspected vulnerabilities privately to the
repository owner. Include affected version, reproduction steps using synthetic data, impact, and
sanitized diagnostic identifiers. Do not test against production tenants without written approval.

Supported versions and disclosure timelines will be published before the first public release.
